# Contributing to Atria Hotel Magelang

First off, thank you for considering contributing to this repository! 

## How Can I Contribute?
1. **Reporting Bugs**: Open an issue if you find broken links, typos, or markdown formatting errors.
2. **Suggesting Enhancements**: Propose new operational metrics, risk assessments, or digital transformation frameworks.
3. **Pull Requests**: Submit PRs for documentation improvements or website updates.

## Pull Request Process
1. Fork the repo (`kongali1720/atria-hotel-magelang`).
2. Create your feature branch (`git checkout -b feature/AmazingImprovement`).
3. Commit your changes (`git commit -m 'Add some AmazingImprovement'`).
4. Push to the branch (`git push origin feature/AmazingImprovement`).
5. Open a Pull Request.
