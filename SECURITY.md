# Security Policy

## Supported Versions
Atria Hotel Magelang Master Plan is an independent research and documentation repository. Security policies apply to our digital website deployments and repository assets.

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |

## Reporting a Vulnerability
If you discover a security vulnerability within our GitHub Pages website or documentation scripts, please report it privately via GitHub issues or contact the repository owner directly at `kongali1720`.
